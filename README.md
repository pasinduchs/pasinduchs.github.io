# Pasindu — Architecture Portfolio

A responsive GitHub Pages portfolio built with plain HTML, CSS and JavaScript. No build tools or packages are required.

## Preview locally

Download or clone this repository, then open `index.html` in a browser. Or run `python -m http.server 8000` in the project folder and visit `http://localhost:8000`. The remote photos and Google Fonts need an internet connection.

## Personalise before launch

- Replace the sample email address and social profile links in `index.html`.
- Replace the architectural reference photographs with your own Revit renders.
- Update the project descriptions and CV note with accurate details.

The gallery entries are clearly labelled as practice studies, not completed client commissions.

## Publish with GitHub Pages

Review this branch first. When you are ready to publish, merge `portfolio-refresh` into `main`. In GitHub, open **Settings → Pages**, choose `main` and `/(root)` as the source, then save. GitHub will show the site address after the build completes. Merging or changing Pages settings may make the site public.
