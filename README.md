# Pasindu Chameera — Civil Engineering Portfolio

A responsive GitHub Pages-compatible portfolio built with plain HTML, CSS and JavaScript. It has no build step.

## Preview on Windows

1. Open File Explorer and open the project’s `outputs` folder.
2. Double-click `index.html` to open the site.
3. Scroll to see the header change from the hero-photo treatment to a solid theme-matched background. Use the sun/moon switch to change themes; the selected theme is saved in that browser.

Keep `styles.css`, `script.js`, `pc-monogram.png`, `Pasindu_Chameera_CV.pdf`, and the `assets` folder beside `index.html`. The `assets` folder holds the supplied portrait and certificate-collection photograph. The house render is the existing remote hero reference image, and Inter is loaded from Google Fonts.

## Check the site

- Select each header link and confirm it reaches Home, About Me, Projects, Skills & Tools, Services, or Contact Me.
- Check the header at the top and after scrolling, at desktop, tablet, and mobile widths. Try both themes and reload to confirm the saved theme persists.
- Select **Download CV** and confirm `Pasindu_Chameera_CV.pdf` opens or downloads.
- The Contact Me form retains the existing Formspree endpoint and native HTML POST. Live submission has not been verified from this environment because DNS could not resolve `formspree.io`.

The uploaded certificate photograph is a single collage; selecting it opens the complete original image at full size. No certificate title, issuing organisation, qualification, or date has been added to the page.

The Projects section is a set of honest placeholders for future genuine Revit screenshots, academic work, and engineering projects. No client work or completed model is claimed. Structural modelling is presented as a future learning direction, not as a current service.

The site has not been published or deployed.
