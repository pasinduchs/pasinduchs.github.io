# Pasindu — Architecture Portfolio

A responsive GitHub Pages portfolio built with plain HTML, CSS and JavaScript. No build tools or packages are needed.

## Preview on Windows

1. Open File Explorer.
2. Go to the project folder and open the `outputs` folder.
3. Double-click `index.html`. Your browser should open the portfolio. Keep `styles.css` and `script.js` beside it; the page loads those files locally. Internet access is needed for the reference photographs and Google Fonts.

If you cloned the GitHub repository instead, open its main project folder and double-click its `index.html`.

## Portfolio content

The gallery is labelled as sample practice work. Its architectural photos are illustrative references, not Revit screenshots or completed client projects. Replace these images and descriptions with your own model views when ready. Replace the sample email and social profile links in `index.html` before sharing the site.

The services section describes beginner-level Revit modelling from supplied 2D residential floor plans, including walls, doors, windows, stairs, floors and roofs.

## Publish later

This version is on the `portfolio-refresh` review branch and has not been merged or deployed. When you decide to publish, review the branch, then merge it into `main`. In GitHub, open **Settings → Pages**, select `main` and `/(root)` as the publishing source, then save. GitHub will show the site address after the build completes.
